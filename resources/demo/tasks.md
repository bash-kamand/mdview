# Project Tasks

Click any checkbox to toggle it — ClaudeView saves the change directly to this file.

## Getting Started

- [x] Install ClaudeView
- [x] Open the demo project
- [x] Open your real Claude Code project with **Open Folder**
- [x] Try the Tasks view (toolbar checklist button)
- [ ] Press `⌘F` to search across all files
- [ ] Press `⌘P` to switch files fast

## Explore the Features

- [ ] Click the outline icon (≡) in the panel header on a long file
- [ ] Hold `⌘` and click a sidebar file to open split view
- [ ] Drag the sidebar edge to resize it
- [ ] Click the sun/moon icon to toggle dark/light mode
- [ ] Check the ~tokens count in the status bar

## For Your Own Projects

- [ ] Write a focused CLAUDE.md (aim for under 500 tokens)
- [ ] Review memory files for accuracy and remove stale entries
- [ ] Clean up slash commands you no longer use
- [ ] Set up a tasks.md in each project
